# Gravity Room VR

A VR arcade game planned for Meta Quest 3: grab objects, throw them into matching gates, and adapt to changing gravity.

## Status

Planning and repository setup. The Unity project and playable build have not been created yet.

## Planned stack

- Unity 6 with URP
- Meta XR Interaction SDK
- Quest controllers for the initial version

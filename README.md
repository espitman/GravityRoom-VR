# Gravity Room VR

A VR arcade game planned for Meta Quest 3: grab objects, throw them into matching gates, and adapt to changing gravity.

## Status

Phase 2 implementation: a reusable grabbable orb, reachable pedestal, one target gate, SDK release throwing, and automatic recovery in the stationary room. Quest acceptance and final throw tuning are pending. The accepted black/white gloves and elbow-down forearms are retained.

## Stack

- Unity 6000.0.83f1 with URP 17.0.4
- Meta XR SDK 205.0.0 and Unity OpenXR 1.16.1
- Quest controllers and Meta hand interaction rig

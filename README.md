# Gravity Room VR

A VR arcade game planned for Meta Quest 3: grab objects, throw them into matching gates, and adapt to changing gravity.

## Status

Phase 1 foundation: Unity project, Meta XR configuration, a stationary test room, controller-driven virtual hands, live tracking diagnostics, and repeatable build/deployment scripts. Gameplay starts in Phase 2.

## Stack

- Unity 6000.0.83f1 with URP 17.0.4
- Meta XR SDK 205.0.0 and Unity OpenXR 1.16.1
- Quest controllers for the initial version
